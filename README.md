# what is it?
Sili is a container management interface via the web. I didn't like other container interfaces like coolify. So I decided to try and make my own.

# Current features
- Overview of containers
- Start, stop, remove container
- Container health visable

# Planned features
- Cli from the container
- Permission system
- Action logging
- Automatic subdomains
- Template containers
- Archive function
- Kata containers(?)
- Podman support
